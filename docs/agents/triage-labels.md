# Triage Labels

技能中使用五个标准 triage 角色名。此文件将角色名映射到 GitHub 实际使用的 label 字符串。

| 技能中的名称      | GitHub Label     | 含义                           |
| ----------------- | ---------------- | ------------------------------ |
| `needs-triage`    | `needs-triage`   | 维护者需要评估此 issue          |
| `needs-info`      | `needs-info`     | 等待报告者补充更多信息          |
| `ready-for-agent` | `ready-for-agent`| 规格明确，AFK 代理可直接接手    |
| `ready-for-human` | `ready-for-human`| 需要人工实现                    |
| `wontfix`         | `wontfix`        | 不做处理                        |

技能中提到某个角色时（如"apply the AFK-ready triage label"），使用对应的 GitHub label。
